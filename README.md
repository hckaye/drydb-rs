# drydb-rs

[DryDB](https://github.com/hadashiA/DryDB) のファイル互換を目指す、Rust製の読み取り専用組み込みKVデータベース。

**現在の状態: 設計段階。** このリポジトリの文書は実装提案であり、Rust実装、互換性テストの合格、性能向上を示すものではありません。

## 目指すもの

シード時に不変のDBファイルを構築し、実行時はB+Treeの必要なページだけを読み込みます。全データのRAM常駐、全件デシリアライズ、起動時の全索引再構築は前提にしません。SQL、実行時更新、トランザクション、WAL、MVCCは対象外です。

互換対象は当面、upstream commit `6b175929491793948e63430c20c2d6f58300d97f` の **DryDB storage format 1.4** に固定します。C#→Rust / Rust→C#の相互読み書きと検索結果の一致をテストで確認し、対応範囲を公開します。

Rust側ではページ所有権、借用、メモリ予算、検索経路を最適化します。rkyvは**レコード単位のvalue codec**として追加し、既存のDryDBファイル構造を置き換えません。C#からrkyvの値をraw bytesとして読むことと、C#で型付きデコードできることは別の互換性です。
